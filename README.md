# Midnight Fridge Roast

A one-line roast of a smart fridge that refuses to open after midnight — the fridge locks at 12:00 and hums like it just beat its owner in a fight over cold pizza. The petty midnight rule is the target; the smug hum is the punchline.

## Entry

> At midnight my fridge locks and hums like it just beat me in a fight over cold pizza.

## How to run

```bash
python3 main.py
```

Writes the single line to `/output/entry.txt` (UTF-8, exactly one line, 85 characters). Python 3.13 standard library only, no network at run time.
